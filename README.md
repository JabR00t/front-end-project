# LifeOS

One platform, all your goals. LifeOS is a personal dashboard built around five pillars, in plain HTML, CSS and JavaScript (no build step).

## Pillars

| Pillar | Focus |
|---|---|
| Productivity & Education | Tasks, calendar, Pomodoro sessions, study goals |
| Health & Wellness | Hydration, sleep, sport habits, wellness journal |
| Reading & Entertainment | Personal library, current books, reading goals |
| Spiritual Life | Customizable reminders, practice tracking, reflection |
| Personal Growth | Short and long-term goals, habits, weekly review, progress |

## Run locally

Open `index.html` in your browser.
